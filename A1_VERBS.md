# German A1 verbs

This table contains **152 teachable verb entries** derived from the
Goethe-Zertifikat A1: Start Deutsch 1 vocabulary inventory.

CEFR does not prescribe one universal vocabulary list, so this project uses the
Goethe adult A1 inventory as its explicit scope. The source entry `gestorben`
is represented by its teachable infinitive `sterben`; the source spelling
`weh tun` is normalized to modern `wehtun`.
