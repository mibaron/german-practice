GERMAN A1 PRACTICE LAB — VERSION 2

FILES
- index.html  -> the app
- data.js     -> lesson content (verbs, flashcards, grammar, exercises)

BROWSER PROGRESS
The app automatically saves progress with browser localStorage:
- correct answers
- attempts and accuracy
- mastered flashcards
- per-item practice history
- last practice mode and position

EXPORT / IMPORT
- Export progress downloads a JSON backup.
- Import progress restores that JSON backup.
- This lets you manually move progress to another browser/device.
- The progress backup does not contain the lesson database.

ADDING MATERIAL
Edit data.js. New lessons can be added without changing index.html.

GITHUB PAGES
Publish index.html and data.js together.
Lesson content is public; personal progress stays in the browser unless you export it.
